Decrypt Wallet Balance

Lihat angka asli active_balance / hold_balance dari t_wallet / t_mutations. Algoritma sama dengan utils.AesDecrypt di backend: AES-GCM, key = m_users.uniq_key, 12 byte pertama hex = nonce. Semua proses jalan di browser (WebCrypto), tidak ada request keluar.

Input

Ctrl+Enter untuk decrypt

Hasil

Encrypt (opsional)
