QR Generator

Generator QR biasa untuk mengubah string QRIS / payload dari response API menjadi QR code yang bisa discan aplikasi pembayaran.

Input

tempel string QR atau response JSON API

Hasil

QR code akan muncul di sini

Cara Pakai

  1. Di halaman Payment Link, jalankan transaksi sampai response API muncul.
  2. Copy response JSON, lalu paste di textarea atas halaman ini.
  3. Klik Ambil dari JSON — field QR akan diekstrak otomatis.
  4. Klik Generate QR, lalu scan dengan aplikasi pembayaran.
